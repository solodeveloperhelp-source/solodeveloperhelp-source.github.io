Политика конфиденциальности FastFile

Последнее обновление: 03.05.2026

FastFile — это файловый менеджер для Android. Приложение предназначено для работы с файлами на устройстве пользователя: просмотр, копирование, перемещение, удаление, архивирование, распаковка, конвертация, OCR, установка APK-файлов и локальный обмен файлами по Wi-Fi.

1. Какие данные собирает приложение

FastFile не требует создания аккаунта.

FastFile не собирает и не продаёт персональные данные пользователя.

Приложение не отправляет файлы пользователя на серверы разработчика без явного действия пользователя.

Большинство функций выполняется локально на устройстве пользователя.

2. Доступ к файлам

FastFile может запрашивать доступ к файлам и папкам устройства, включая расширенный доступ к файлам Android, если это необходимо для работы файлового менеджера.

Этот доступ используется для следующих функций:

  • просмотр файлов и папок;
  • копирование, перемещение и удаление файлов;
  • создание файлов и папок;
  • работа с архивами;
  • просмотр свойств файлов;
  • поиск файлов;
  • работа с корзиной приложения;
  • конвертация файлов;
  • просмотр медиафайлов;
  • установка APK-файлов по действию пользователя.

FastFile не использует доступ к файлам для скрытого сбора данных.

3. Корзина приложения

При удалении некоторых файлов приложение может перемещать их во внутреннюю корзину FastFile.

Файлы в корзине остаются на устройстве пользователя и могут быть восстановлены или окончательно удалены пользователем.

4. OCR

FastFile может использовать OCR для распознавания текста на изображениях.

OCR выполняется для файлов, выбранных пользователем. Распознанный текст отображается внутри приложения.

Приложение не отправляет изображения или распознанный текст на серверы разработчика.

5. Архивы и конвертация

FastFile может распаковывать и создавать архивы, а также выполнять конвертацию некоторых типов файлов.

Все операции выполняются с файлами, выбранными пользователем.

Приложение не передаёт содержимое архивов или конвертируемых файлов разработчику.

6. APK-файлы и установщик

FastFile может открывать и устанавливать APK-файлы по запросу пользователя.

Приложение может запрашивать разрешение на установку приложений из внешних источников. Установка выполняется только после явного действия пользователя и подтверждения Android.

FastFile не устанавливает приложения без согласия пользователя.

7. Список установленных приложений

Некоторые функции FastFile могут использовать информацию об установленных приложениях на устройстве, например для работы с APK, системными настройками, очисткой кеша или анализа приложений.

Эта информация используется только локально на устройстве и не продаётся третьим лицам.

8. Локальный доступ по Wi-Fi

FastFile может запускать локальный HTTP-сервер для доступа к файлам устройства из той же локальной сети.

Эта функция включается только пользователем.

При включении локального Wi-Fi доступа другие устройства в той же сети могут получить доступ к выбранным файлам через адрес, показанный в приложении.

Пользователь должен использовать эту функцию только в доверенной сети.

9. Accessibility Service

FastFile может использовать Accessibility Service для автоматизации некоторых действий, связанных с очисткой кеша приложений.

Эта функция не предназначена для сбора личных данных, чтения сообщений, паролей, платёжной информации или другого чувствительного содержимого экрана.

Accessibility Service используется только для выполнения действий, явно запущенных пользователем.

Пользователь может отключить этот сервис в настройках Android в любой момент.

10. Логи приложения

FastFile может сохранять локальные технические логи для диагностики ошибок.

Логи хранятся на устройстве пользователя.

Пользователь может самостоятельно отправить логи разработчику, если хочет сообщить об ошибке.

11. Реклама и аналитика

Если в приложении используется реклама, рекламные SDK могут обрабатывать технические данные устройства в соответствии со своими политиками конфиденциальности.

FastFile не продаёт персональные данные пользователя.

Если реклама или аналитика отключены в конкретной версии приложения, соответствующие SDK могут быть неактивны.

12. Передача данных третьим лицам

FastFile не передаёт файлы пользователя третьим лицам без действия пользователя.

Пользователь может самостоятельно поделиться файлом через системное меню Android. В этом случае обработка файла зависит от выбранного пользователем приложения.

13. Безопасность

FastFile использует стандартные механизмы Android для доступа к файлам, установки APK, биометрии, разрешений и системных настроек.

Пользователь несёт ответственность за файлы, которые он открывает, удаляет, устанавливает или передаёт через приложение.

14. Дети

FastFile не предназначен специально для детей младше 13 лет.

Приложение не собирает намеренно персональные данные детей.

15. Изменения политики

Политика конфиденциальности может обновляться при изменении функций приложения, разрешений или требований Google Play.

Актуальная версия политики публикуется на этой странице.
