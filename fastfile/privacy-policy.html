Политика конфиденциальности FastFile

Последнее обновление: 21.05.2026

Приложение: FastFile

Пакет приложения: com.solo.fastfile

Разработчик: SoloDeveloperHelp

Email: solo.developer.help@gmail.com

FastFile — это файловый менеджер для Android. Приложение предназначено для работы с файлами на устройстве пользователя: просмотр, поиск, копирование, перемещение, переименование, удаление, архивирование, распаковка, конвертация, просмотр медиафайлов, работа с APK-файлами, локальный обмен файлами по Wi-Fi и дополнительные инструменты управления файлами.

FastFile не требует создания аккаунта, не использует облачную синхронизацию и не загружает содержимое файлов пользователя на серверы разработчика.

1. Какие данные использует приложение

Для работы функций FastFile может обрабатывать на устройстве пользователя следующие данные:

  • локальные файлы и папки, которые пользователь открывает или выбирает;
  • имена файлов, пути, размеры, даты изменения, типы файлов и миниатюры;
  • содержимое файлов при просмотре, конвертации, архивировании, распаковке или других действиях, выбранных пользователем;
  • информацию об установленных приложениях, если пользователь открывает раздел приложений, работает с APK или запускает очистку кеша;
  • настройки FastFile: язык, тема, параметры интерфейса, параметры безопасности, корзина, root-кнопка, настройки рекламы и другие локальные параметры;
  • данные отчёта об ошибке, если пользователь сам отправляет его разработчику: описание проблемы, категория, время, контакт, выбранные вложения, версия приложения и технические сведения об устройстве;
  • технические рекламные данные, которые может обрабатывать рекламный SDK Start.io.

2. Что FastFile не делает

  • FastFile не продаёт файлы пользователя.
  • FastFile не загружает фотографии, видео, документы, музыку, архивы или другие локальные файлы на серверы разработчика.
  • FastFile не требует регистрации или входа в аккаунт.
  • FastFile не выполняет облачную синхронизацию файлов.
  • FastFile не устанавливает приложения без действия и подтверждения пользователя.
  • FastFile не содержит пользовательской функции записи логов.
  • FastFile не содержит функции отправки диагностических логов разработчику.

Передача файлов может происходить только тогда, когда пользователь сам выбирает системное действие Android: «Поделиться», «Открыть в другом приложении», установку APK или локальный сетевой доступ.

3. Доступ к файлам

FastFile может запрашивать доступ к файлам и папкам устройства, включая расширенный доступ к файлам Android, если это необходимо для работы файлового менеджера.

Этот доступ используется для следующих функций:

  • просмотр файлов и папок;
  • копирование, перемещение, переименование и удаление файлов;
  • создание файлов и папок;
  • работа с архивами;
  • просмотр свойств файлов;
  • поиск файлов;
  • работа с корзиной приложения;
  • конвертация файлов;
  • просмотр фото, видео, музыки, PDF и документов;
  • установка APK/APKS/XAPK/APKM по действию пользователя.

FastFile не использует доступ к файлам для скрытого сбора данных.

4. Корзина приложения

При удалении некоторых файлов приложение может перемещать их во внутреннюю корзину FastFile. Файлы в корзине остаются на устройстве пользователя и могут быть восстановлены или окончательно удалены пользователем.

Если корзина отключена, очищена или файл удалён окончательно, восстановление средствами приложения может быть невозможно.

5. Архивы, PDF и конвертация

FastFile может распаковывать и создавать архивы, выполнять конвертацию некоторых типов файлов, работать с PDF-инструментами и открывать поддерживаемые форматы файлов, если такие функции доступны в текущей версии приложения.

Все такие операции выполняются с файлами, выбранными пользователем. FastFile не отправляет содержимое архивов, PDF, изображений, документов или конвертируемых файлов разработчику.

6. APK-файлы и установщик

FastFile может открывать, анализировать и устанавливать APK/APKS/XAPK/APKM-файлы по запросу пользователя.

Приложение может запрашивать разрешение на установку приложений из внешних источников. Установка выполняется только после явного действия пользователя и системного подтверждения Android.

FastFile не устанавливает приложения без согласия пользователя.

7. Список установленных приложений

Некоторые функции FastFile могут использовать информацию об установленных приложениях на устройстве, например для раздела приложений, APK-инструментов, системных настроек, очистки кеша или анализа приложений.

Эта информация используется для функций приложения и не продаётся разработчиком третьим лицам.

8. Локальный доступ по Wi-Fi

FastFile может запускать локальный HTTP-доступ для передачи файлов между устройствами в одной сети. Эта функция включается только пользователем.

При включении локального Wi-Fi доступа другие устройства в той же сети могут получить доступ к выбранным файлам через адрес, показанный в приложении.

Пользователь должен использовать эту функцию только в доверенной сети.

9. Accessibility Service

FastFile может использовать Accessibility Service для автоматизации действий, связанных с очисткой кеша приложений.

Accessibility Service не предназначен для сбора личных данных, чтения сообщений, паролей, платёжной информации или другого чувствительного содержимого экрана.

Сервис используется только для действия, явно запущенного пользователем, например для перехода по системным экранам Android и нажатия доступных системных кнопок очистки кеша.

Пользователь может отключить этот сервис в настройках Android в любой момент.

10. Отчёты об ошибках

FastFile может содержать функцию отправки отчёта об ошибке. Отчёт отправляется только после явного действия пользователя.

Отчёт может содержать описание проблемы, выбранную категорию, время возникновения проблемы, контакт пользователя, версию приложения, сведения об устройстве и вложения, которые пользователь сам выбрал для отправки.

FastFile не прикрепляет диагностические логи к отчёту об ошибке.

11. Проверка обновлений

FastFile может показывать пользователю уведомление или экран с предложением обновить приложение, если доступна новая версия в Google Play.

При переходе к обновлению пользователь открывает страницу FastFile в Google Play. Обработка данных при использовании Google Play выполняется в соответствии с правилами и политиками Google Play.

12. Реклама Start.io

FastFile использует рекламный SDK Start.io для показа баннерной рекламы. Реклама может отображаться внутри приложения, например в области выбора памяти или на других экранах, если это предусмотрено текущей версией приложения.

Start.io SDK может собирать, обрабатывать и передавать технические данные, необходимые для показа, ограничения частоты, персонализации, предотвращения мошенничества, аналитики и измерения рекламы. Такие данные могут включать:

  • Advertising ID Android;
  • IP-адрес;
  • сведения об устройстве, модели, операционной системе и настройках;
  • сведения о сети, операторе, Wi-Fi и подключении;
  • название приложения и идентификатор приложения;
  • данные о рекламных показах, кликах и взаимодействиях с рекламой;
  • приблизительное местоположение или другие технические данные, если они доступны SDK и разрешены применимыми правилами.

Start.io может показывать собственное уведомление или окно согласия на персонализированную рекламу, если это требуется законом в регионе пользователя.

Политика конфиденциальности Start.io доступна по адресу: https://www.start.io/policy/privacy-policy-site/

13. Кнопка «Убрать рекламу»

В настройках FastFile может быть доступна функция «Убрать рекламу». Если она включена, приложение скрывает рекламный баннер в интерфейсе FastFile, если такая возможность поддерживается текущей версией приложения.

Эта функция не изменяет политику Start.io и не управляет рекламными настройками Android. Пользователь также может управлять Advertising ID и персонализацией рекламы в настройках Android и Google Play Services.

14. Передача данных третьим лицам

FastFile не передаёт файлы пользователя третьим лицам без действия пользователя.

Передача данных третьим лицам может происходить в следующих случаях:

  • пользователь самостоятельно делится файлом через системное меню Android;
  • пользователь открывает файл в другом приложении;
  • пользователь запускает локальный Wi-Fi доступ;
  • пользователь отправляет отчёт об ошибке через выбранное приложение;
  • пользователь открывает страницу приложения в Google Play для обновления;
  • рекламный SDK Start.io обрабатывает технические рекламные данные для показа и измерения рекламы.

15. Безопасность

FastFile использует стандартные механизмы Android для доступа к файлам, установки APK, биометрии, разрешений и системных настроек.

Пользователь несёт ответственность за файлы, которые он открывает, удаляет, устанавливает, конвертирует или передаёт через приложение.

16. Дети

FastFile не предназначен специально для детей. Приложение не обозначается как приложение, предназначенное для детей.

Если ребёнок использует приложение, это должно происходить только с разрешения родителей или законных представителей.

17. Права пользователя

Пользователь может:

  • отозвать разрешения FastFile в настройках Android;
  • очистить данные FastFile через настройки Android;
  • удалить приложение;
  • отключить Accessibility Service в настройках Android;
  • сбросить или удалить Advertising ID в настройках Android/Google Play Services;
  • управлять персонализацией рекламы в настройках Android;
  • связаться с разработчиком по вопросам конфиденциальности.

18. Изменения политики

Политика конфиденциальности может обновляться при изменении функций приложения, разрешений, рекламной интеграции, сторонних SDK или требований Google Play.

Актуальная версия политики публикуется на этой странице и может также отображаться внутри приложения.
